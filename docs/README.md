## Como contribuir com a documentação

1. Escreva título claro com `#` no topo do arquivo.
2. Inclua uma breve introdução explicando objetivo e público.
3. Prefira instruções passo a passo com exemplos de comando.
4. Mantenha seções curtas usando `##` e `###`.
