# Changelog (Alias)

Este arquivo existe para compatibilidade com ferramentas e usuários que buscam o changelog em minúsculas.

## Onde está o changelog oficial

Use o arquivo principal: [CHANGELOG.md](./CHANGELOG.md)

## Passo a passo para atualizar versões

1. Edite `docs/CHANGELOG.md` com a nova versão.
2. Registre data, itens de adição/alteração/correção e impacto de segurança.
3. Atualize as notas de release em [RELEASE.md](./RELEASE.md).
